# Rabbit Sprite Assets — Design

**Date:** 2026-07-01
**Phase:** Bloom v1 polish — replace placeholder-rendered animals with real sprite assets.
**Scope:** Rabbit only, as the reference implementation every future species copies.

## Goal

Render the rabbit from a real pixel-art spritesheet driven by the existing
Asset Registry, Sprite Asset Pipeline, Animation Framework and Content Pack
system. No new frameworks, no renderer redesign, no gameplay changes. After
this, every remaining species needs only **one spritesheet + one content-pack
edit** — zero engine or renderer edits.

## Existing systems (already built — reused as-is)

- `AssetDescriptor` supports `spritesheet` + `frames` (rect slices), `animations`
  (clips keyed by state), `staticFrame`, and `metadata` (placeholder palette).
- `AssetRegistry.preloadPack` slices a spritesheet image into per-frame textures,
  guarded so a missing/broken file degrades to the placeholder — never crashes.
- `AnimationController` plays clips by frame id; deterministic playback.
- `PixiRenderer.resolveTexture(instanceKey, assetId, state, deltaMs)` already
  resolves an animated frame (via a per-instance controller) or the static
  texture, else returns null → primitive placeholder. It is fully generic and
  never names a species. Clip ids equal `AnimalState` values, so
  `resolveTexture(state)` resolves directly.

## The one real gap

Content packs call `assetRegistry.registerPack()` (descriptors only). Nobody
loads their textures — `PixiRenderer.init` only preloads `PLACEHOLDER_ASSET_PACK`.
So a rabbit spritesheet would register but never load, and the renderer would
always fall back to the placeholder. This is a missing wire, not a redesign.

## Changes

### 1. Spritesheet art — `public/assets/rabbit.png`

- Pixel art. 32×32 frames, horizontal strip (224×32). Cream/grey rabbit matching
  the current placeholder palette (body `0xd8cfc0`, dark `0xb8ae9c`).
- 7 frames: `idle_0`, `idle_1`, `walk_0`, `walk_1`, `walk_2`, `walk_3`, `sleep_0`.
- Generated by a committed no-dependency Node script
  (`scripts/gen-rabbit-sheet.mjs`, hand-rolled PNG encoder via `zlib`) so the art
  is reproducible and editable. Hosted in `public/` → served at `/assets/rabbit.png`
  by Vite/Tauri, loaded by the existing `Assets.load` path unchanged.

### 2. `rabbit.pack.ts` — the only content edit

Add to the `animal.rabbit` descriptor (keep `metadata` palette for fallback):

- `spritesheet: '/assets/rabbit.png'`
- `frames`: 7 rects (`idle_0`…`sleep_0`)
- `animations`:
  - `idle`: `[idle_0, idle_1]`, `frameDurationMs: 500`, `loop: true` (subtle)
  - `walking`: `[walk_0, walk_1, walk_2, walk_3]`, `frameDurationMs: 120`, `loop: true`
  - `sleeping`: `[sleep_0]`, `frameDurationMs: 0`, `loop: false` (single held frame)
- `staticFrame: 'idle_0'`

No renderer edit. Clip ids (`idle`/`walking`/`sleeping`) are the `AnimalState`
values the FSM emits for rabbit.

### 3. Preload wire — generic, one-time

- `AssetRegistry.preloadAll()`: preload textures for **every** registered
  descriptor that references art (reuses `assetReferencesArt` + the existing
  `preloadPack` slicing logic). Species-agnostic.
- `PixiRenderer.init` calls `await assetRegistry.preloadAll()` once, after the
  placeholder pack loads. No species names in the renderer.

### 4. Fallback (unchanged)

Load failure leaves the descriptor with no cached texture → `getStaticTexture` /
`getFrameTexture` return null → renderer draws the primitive from `metadata`.
Guarded try/catch already exists in `preloadPack`. Nothing crashes.

## Testing (TDD)

- `AssetRegistry.preloadAll` loads art-referencing descriptors and skips
  placeholder-only ones; never throws on a broken/missing source.
- `rabbit.pack.ts` registers `spritesheet` + all 7 `frames` + 3 `animations` +
  `staticFrame`, and still carries the `metadata` palette.
- Clip ids are a subset of `AnimalState`; rabbit declares `idle`/`walking`/`sleeping`.
- Fallback: with no texture loaded, static/frame lookups return null (existing
  behaviour preserved).

## Out of scope (untouched)

AI, movement, facing/sprite-flip, other species, rare animals, marketplace,
weather, particles, lighting. No new frameworks. No renderer species code.

## Future-proofing

After rabbit: a new species is one `public/assets/<species>.png` + the same
descriptor fields in its `*.pack.ts`. `preloadAll` picks it up automatically;
the renderer resolves its frames through the same generic path.
